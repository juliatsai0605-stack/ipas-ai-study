給零程式基礎、想取得「AI應用規劃師（數據分析）」的學習者。先打地基，再考初級，最後考中級科目1＋科目2。

返回備考室

一、考試規則重點

  • 初級兩科：人工智慧基礎概論、生成式AI應用與規劃。同時報考須平均70分，且每科不低於60分。
  • 中級：科目1必考；科目2（大數據）取得數據分析證書，科目3（機器學習）取得機器學習證書；兩科均須70分。單科70分以上成績保留三年度。
  • 中級科目2、3約25%為程式題（Python語法、程式邏輯、程式片段解析）。依據：官網公告（2026-03-31）。
  • 116年考試日期尚未公告。115年為初級3、5、8、11月，中級5、11月，可作為排程參考。

三、階段0｜零基礎地基（免費資源）

Python 基本語法（第1～3週）

  • 練習環境：Google Colab，瀏覽器即可寫程式，免安裝。
  • Python 官方教學（繁體中文）：讀第3～5章。
  • Kaggle Learn：Python（免費，英文介面，附練習）。
  • 必會：變數與型別、list、dict、if、for、函式、索引與切片。

資料分析工具（第4～6週）

  • Kaggle Learn：Pandas、Data Visualization。
  • McKinney《Python for Data Analysis》第3版官方免費線上版（英文）：第4、5、7、9章。
  • 歷屆題常見語法：pd.read_csv df.head df.describe df.isnull().sum() fillna dropna groupby(...).mean() sort_values value_counts merge np.std(axis=0) plt.hist plt.boxplot sns.heatmap。

統計入門（第7～8週）

  • 均一教育平台：國高中數學的統計與機率單元（免費，單元名稱以平台為準）。
  • 重點放在「該用哪種方法、怎麼解讀結果」，不必背公式。

七、搭配 NotebookLM（選用）

  1. 下載上列官方PDF，存到自己的 Google 雲端硬碟。
  2. 在 NotebookLM 建兩本筆記本：初級一本、中級數據分析一本，各自只放對應的指引與試題。
  3. 提問時要求「只根據來源回答，來源沒有的請標明來源未提及」。
  4. 語音摘要可自訂：「以臺灣用語，對零程式基礎的學習者解釋本章最常考的三個觀念，各舉一個生活例子。」

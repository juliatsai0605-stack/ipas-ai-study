No Code / Low Code 的基本概念。

這節來談No Code / Low Code 的基本概念。先抓住哪個重點呢？

No-code以視覺元件組合流程，Low-code允許在部分位置加程式。低門檻不是沒有系統設計，仍要定義觸發條件、資料流、分支、錯誤處理及權限。

最容易混淆的地方是什麼？

平台提供的元件與整合能力會限制可做的事。選工具時先確認外部資料接入、匯出能力及可維護性，不要只看第一個展示畫面能多快完成。

換成情境怎麼記？

收到表單後先驗證欄位、查資料、整理結果再寄通知；每一步都要知道失敗時是否重試，以及是否可能重複寄送。 記住：少寫程式，仍要設計流程。

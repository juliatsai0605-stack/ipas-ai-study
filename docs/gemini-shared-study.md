# 公務AI × iPAS 共學

沿用原網站、Supabase帳號及私人學習紀錄。Gemini／NotebookLM是教學與教材工具；網站是題庫與作答紀錄正本。不另開第二個網站，不發每日通知。

## 使用入口

原網站上方「Gemini共學」→選範圍與主題→產生並複製導師指令。用本人Google帳號在Gemini建立一個Gem「公務AI × iPAS 導師」，將指令放入指示。教材放在同一個NotebookLM筆記本，標題前綴分為「共通」「公務AI」「iPAS初級」「iPAS中級」，保留官方版本及勘誤表。若帳號支援在Gemini選取筆記本，可直接使用；否則明確選取本次需用的教材。不要假設兩服務會自行同步所有內容。

公務AI認證的正式名稱及考綱未查證，暫作「公務AI應用練習」，不宣稱已涵蓋認證。既有roadmap.html官方連結作為教材起點，仍須核對版本，不把舊整理日期當最新查證。

學完讓Gemini輸出指令內約定的JSON，貼回同一網站；待核對來源、答案後練習。重複ID略過；共用題採多個考試標籤，保留一份題目與一組練習紀錄。自編題與既有官方題庫及模擬考分開計分。訂正原因可留存，錯題會顯示上次結果；此版尚無自動間隔複習排程或完整考綱達成率。

## 實作範圍與驗收

- 無API金鑰、無付費服務、無背景Google資料讀取或自動上傳。Gemini網頁版登入不等於網站可直接呼叫API。
- 批次1至50題、總庫500題；必要欄位與HTTPS來源驗證；匯入不能自行宣稱已核對。
- 共用概念同題多標籤；答案含複選；錯題原因更新同一筆作答。
- 沿用原帳號雲端同步；切換帳號立即關閉共學視窗，清除當前匯入文字及顯示；不改資料庫schema。
- tests/gemini-study.mjs 驗證格式、來源核對、共用題、計分、訂正、帳號隔離與行動版寬度。雲端實際登入與Google帳號Gem設定須另外實測，不以mock通過代替正式驗收。

## 已知限制

這是可測試的整合程式，建立Gem與NotebookLM仍需可用的本人瀏覽器連線；不能由GitHub程式變更代替。尚未建立Google帳號內的Gem、NotebookLM或正式考綱對照。不得將PR提交當成已上線。
